useMorphSvgHover

Compressed map of the shared MorphSVG hover hook. Print-friendly.

Job

Wire chalk SVG icons so hover morphs to a final shape and leave morphs back — without loading MorphSVG until needed, without stale async races, and without reduced-motion users getting motion.

Call site (e.g. Game.tsx): pass a path selector + two MorphAnimate fns; spread onMouseEnter / onMouseLeave and attach wrapperRef / svgRef.

Return value

Field Attach to
wrapperRef Hover target div (also path query root)
svgRef <svg> (viewBox tweens)
groupRef Optional <g>
onMouseEnter morph(true)
onMouseLeave morph(false)

Refs (mutable state, no re-render)

Ref Purpose
pathsRef Cached querySelectorAll result; cleared if selector changes
tweensRef Active morph tweens; killed before new morph / on unmount
hoveredRef Desired hover state when async load resolves
loadGenRef Monotonic generation; stale then callbacks bail
animateFinalRef / animateOriginalRef Latest animate fns (synced in an effect)
pathSelectorRef Latest CSS selector string

Effects vs handlers

Where What runs
Effect Sync animate fn refs; reset path cache on selector change; kill tweens on unmount
Handler (morph) Reduced-motion guard → bump gen → lazy-load → validate → kill → animate

morph(wantHover) flow

if prefersReducedMotion() → return hoveredRef = wantHover gen = ++loadGenRef loadMorphGsap().then(gsap => { if gen !== loadGenRef → return // newer call won if hoveredRef !== wantHover → return // desire flipped if !wrapperRef → return // unmounted killTweens() tweens = wantHover ? animateFinalRef(gsap, ctx) : animateOriginalRef(gsap, ctx) })
