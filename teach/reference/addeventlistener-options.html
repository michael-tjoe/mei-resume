addEventListener options

Cheat sheet for the options object your hook forwards in hooks/useEventListener.ts. 

element.addEventListener(type, listener, {
  capture,  // boolean — listen during capture phase (default false)
  once,     // boolean — auto-remove after first call (default false)
  passive,  // boolean — promise never to call preventDefault()
  signal,   // AbortSignal — remove when controller.abort()
});

Option → meaning

Option If true… In your hook
capture Runs on the way down the tree (before descendants). Passed through; also needed for removeEventListener.
once Fires at most once, then browser removes it. Passed through; cleanup still safe.
passive You will not cancel the event; browser can scroll ASAP. Used as true for resize in useHorizontalScroll.
signal Listener dies when that AbortSignal aborts. Passed through; React effect cleanup is the usual teardown.
Hook-only options: target and enabled are not DOM options — they control where/whether the hook attaches. See Lesson 02.

removeEventListener match keys

Per MDN, removal matches type + listener + capture. once / passive / signal are not part of the identity. 

// your hook cleanup
element.removeEventListener(eventName, listener, capture);

When to set passive

  • Prefer passive: true for scroll / wheel / touch / resize handlers that only observe (never preventDefault).
  • Spec default is false; some browsers default wheel/touch on document-level nodes to true — set explicitly when it matters. (MDN)
