Fake horizontal scroll

Vertical page scroll, pinned section, horizontal x on a child.

Shape

container  ← pin: true (stays in viewport)
  panels   ← gsap.to({ x: -distance })  scrubbed by scroll

Distance

distance = max(0, panels.scrollWidth − window.innerWidth)

Tween target: x: () => −distance. ScrollTrigger end: () => \`+=${distance}\` so vertical travel matches horizontal travel.

Must-haves

  • ease: "none" — linear map from scroll → progress
  • scrub — progress follows scrollbar (number = lag seconds)
  • pin: true — freeze the container, animate the child
  • invalidateOnRefresh: true — re-read function-based values on refresh

Your component map

  • containerRef → trigger + pin target
  • panelsRef → tweened element (x)
  • isDesktop → skip setup / tear down on mobile

Cleanup

tween.scrollTrigger?.kill(true)
tween.kill()
gsap.set(el, { clearProps: "…" })
ScrollTrigger.refresh()  // after resize / layout change
